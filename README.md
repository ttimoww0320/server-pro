# Server-pro.uz — сайт компании

Статический сайт (HTML/CSS/JS, без сборки) на основе шаблона [AirCon — AC Repair Website Template](https://htmlcodex.com/ac-repair-website-template) от HTML Codex, адаптированного под нужды компании.

## Запуск

Сборки нет — это чистые HTML/CSS/JS файлы. Проще всего поднять локальный статический сервер из корня проекта, например:

```bash
python -m http.server 8000
# или
npx serve .
```

и открыть `http://localhost:8000/index.html`. Открывать `index.html` напрямую через `file://` тоже работает, но некоторые библиотеки (например, iframe с картой) ведут себя стабильнее через http-сервер.

`scss/` — это исходники Bootstrap из шаблона, они не подключены ни к какой сборке и не используются в проде напрямую. Продакшен-стили — `css/bootstrap.min.css` и `css/style.css`, их и нужно редактировать.

## Структура

- `*.html` — страницы сайта (10 шт: index, about, service, feature, project, team, testimonial, quote, contact, 404)
- `css/`, `js/`, `lib/` — стили, скрипты и подключаемые библиотеки (jQuery, Bootstrap, WOW.js, OwlCarousel и т.д., частично с CDN, частично локально)
- `img/` — изображения
