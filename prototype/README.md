# Прототип новой главной ServerPro

Статический прототип главной страницы нового сайта — версия **v0.15** от 2026-07-12.

## Как смотреть

Открыть `index.html` в браузере — файл самодостаточный (все стили внутри, из внешнего подключаются только Google Fonts). Ничего собирать не нужно.

## Что внутри

- Hero + три направления (Цифровизация промышленности · Цифровой город · Управление и ИИ)
- «Узнаёте себя?» — 12 карточек типовых ситуаций заказчика и решений
- Стек мониторинга L0–L3
- Офис и производственная площадка
- Собственный бренд Юлдуз (оповещение ГО и ЧС, «Планшет руководителя»)
- Отрасли, технологии и партнёры
- «Как мы работаем» — 4 шага от идеи до цели в цифрах
- CTA + форма (демонстрационная, без бэкенда)

## Статус

Рабочий прототип для обсуждения — **не для публикации**. Ссылки «Страница бренда Юлдуз» (`yulduz.html`) ведут на ещё не созданную страницу. Мобильная версия проверена (375px), меню-бургер работает без JS.
